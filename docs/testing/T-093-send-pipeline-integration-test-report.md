## Defects

Both defects are fixed. The frequency cap was already holding.

1. `findOrCreateRecipient` now uses the shared unique-violation check, which reads Postgres `23505` from Drizzle's `error.cause`. Six parallel first sends for a new address create one recipient.
2. `processSendEmailJob` sets `acceptedId` only after the provider id is non-empty. A blank id is a permanent failure: the message is marked `failed` and the claim is not treated as an accepted send.
